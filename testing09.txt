## Langkah Testing:

### A. Test Dashboard Data Sync

1. Buka: https://lapor-ac.vercel.app/dashboard
2. Catat angka "Tiket Terbuka" saat ini
3. Buat laporan baru via QR Code atau form langsung:
   - Buka: https://lapor-ac.vercel.app/report/new?sku=[SKU_ASET]
   - Isi form dan submit
4. Refresh halaman Dashboard
5. Verifikasi: Angka "Tiket Terbuka" harus bertambah 1

### B. Test Ticket List UI

1. Buka: https://lapor-ac.vercel.app/admin/tickets
2. Verifikasi tampilan:
   [x] Header dengan ikon tiket dan judul "Tiket Laporan Kerusakan"
   [x] Kolom search terlihat di kanan atas
   [x] Tombol filter: Semua, Butuh Validasi, Diproses, Selesai
   [x] Tabel data dengan kolom: ID, Informasi Aset, Detail Laporan, Reporter, Status, Tindakan
   [x] Footer dengan legenda warna dan timestamp "Last sync"

### C. Test Search Functionality

1. Di halaman Ticket List, ketik di kolom search:
   - Cari berdasarkan ID tiket (contoh: "5")
   - Cari berdasarkan nama aset (contoh: "AC")
   - Cari berdasarkan SKU (contoh: "DPM")
   - Cari berdasarkan nama pelapor
2. Verifikasi: Tabel harus filter secara real-time sesuai keyword

### D. Test Filter Status

1. Klik tombol "Butuh Validasi"
   - Verifikasi: Hanya tiket dengan status pending_validation yang tampil
2. Klik tombol "Diproses"
   - Verifikasi: Hanya tiket dengan status open/assigned/in_progress yang tampil
3. Klik tombol "Selesai"
   - Verifikasi: Hanya tiket dengan status resolved/closed yang tampil
4. Klik tombol "Semua"
   - Verifikasi: Semua tiket tampil

### E. Test Validation Actions

1. Filter ke "Butuh Validasi"
2. Klik tombol "Validasi" pada salah satu tiket
3. Konfirmasi dialog yang muncul
4. Verifikasi: Tiket berpindah ke tab "Diproses" dan status berubah ke "open"

5. Klik tombol "X" (Tolak) pada tiket lain
6. Konfirmasi dialog
7. Verifikasi: Tiket ditandai sebagai "False Alarm" dan hilang dari daftar aktif

### F. Test Empty State

1. Gunakan search dengan keyword yang tidak ada (contoh: "xyzabc123")
2. Verifikasi: Tampilan "Data Tidak Ditemukan" dengan tombol "Reset Semua Filter"
3. Klik "Reset Semua Filter"
4. Verifikasi: Kembali ke tampilan semua tiket
